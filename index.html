¿Cómo funciona el Método de Bisección?

01

Teorema de Bolzano

Si f es continua en [a, b] y f(a)·f(b) < 0, entonces existe al menos una raíz en (a, b).

02

Punto Medio

Se calcula c = (a + b) / 2 y se evalúa f(c). Si f(a)·f(c) < 0, la raíz está en [a, c]; si no, en [c, b].

03

Convergencia

Cada iteración reduce el intervalo a la mitad. El error está acotado por (b - a) / 2ⁿ, garantizando convergencia lineal.

04

Ventajas

Siempre converge si se cumple el criterio de Bolzano. Es robusto y simple, aunque más lento que métodos de orden superior.
